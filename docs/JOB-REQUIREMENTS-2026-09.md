## Requirement-to-learning mapping

This is the project's curriculum interpretation of the postings, not the employers' prescribed training plan. Core means required in this learning track; role branch means required preparation when targeting the relevant posting. All additions below are planned until implementation and independent evidence exist.

| Requirement group / evidence | Coverage and priority | Concrete implementation and interview evidence |
|---|---|---|
| Python, OOP, debugging, data structures — J01/J02/J09 | Core, foundations and advanced track | Daily command/service/storage work; unseen coding variations; explain complexity, state ownership and failure handling |
| Advanced SQL/PLSQL and optimization — J01/J02/J03 | Core, validate existing strengths | Window/as-of queries, execution plans and reconciled migration from a synthetic reference batch |
| ETL/ELT, warehousing and modelling — J01/J02/J06/J07/J08 | Core, explicit ETL track | Extract/transform/load stages, incremental versus full rebuild, dimensions/facts, late corrections and backfill |
| Pandas/NumPy/PyArrow; SciPy where relevant — J02/J09 | Core dataframe/file-format literacy; SciPy exercise for J02 | Implement one transformation, inspect dtypes/nulls, compare memory and Parquet conversion; choose a relevant numerical routine and explain its assumptions |

## Changes to the plan from this review

Make ETL/ELT a named track, bring dataframe/Parquet fundamentals forward before Spark optimization, explicitly add metadata/catalogue/lineage exercises, and add API/caching plus platform-specific preparation branches. Retain the Python → trusted data → cloud/Spark → applied AI → reliability progression. These changes improve coverage; they do not make every sampled role an immediate fit.

Use [ETL and interview preparation](ETL-AND-INTERVIEW-TRACK.md), [technology depth](TECHNOLOGY-DEPTH.md), and [production deployment](PRODUCTION-DEPLOYMENT.md) to implement this mapping. At each four-week planning review, turn the next relevant gap into a focused issue; leave future gaps visible rather than squeezing them into the first 30 days.
